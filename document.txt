Tenant Customer API
Aggregator Tenant API documentation helps you to integrate API's for your mobile or own web solution. It will help you integrate your system with shipping solution.
📌 Steps in the Flow
Login / Authentication

Obtain an authentication token using your registered credentials.

This token will be required for all subsequent API requests.

Create Warehouse

Define your warehouse(s) with address and contact details.

All pickups will be scheduled from here.

Create Order

Submit shipment details including customer info, items, and delivery address.
Get Closed Rate Options

Fetch available logistics partners, shipping services, and pricing.
Assign Courier

Choose LSP & service (must match an option from the rate options API).
Create Pickup Request

Schedule the pickup for your order from the warehouse.
Get Packing Slip

Download/print the order’s packing slip to attach to the parcel.

POST
closedRateOptions
/customer_api/rates
Endpoint Description
Fetch courier rate options instantly based on origin/destination pincodes, weight, and shipment details.

This does not require an order UUID and is typically used for:

Pre-checking courier charges

Checkout page shipping estimations

Comparing courier partners before order creation

⚠️ Important:

The values of lspId and service returned in this API must be used exactly in the [Assign Courier API] to confirm courier allocation.

If you pass incorrect values, the assign step will fail.

Method: POST
URL: https://testbe.shipingtech.in/customer_api/rates -Devlopment

https://backend.shipingtech.in/customer_api/rates - Production

Headers

The following header is mandatory for this API:

Key	Value	Required
x-api-key	key	Yes
